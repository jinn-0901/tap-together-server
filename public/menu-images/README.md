# 메뉴 사진 폴더

여기에 실제 메뉴 사진을 올리면 "쉬운 화면 모드"에서 이모지 대신 사진으로 보여줍니다.

- 파일명은 반드시 메뉴 id와 동일하게 (예: `americano.jpg`, `cafe-latte.jpg`)
- 지원 메뉴 id 목록: americano, cafe-latte, strawberry-latte, choco-latte, green-tea, yuja-tea, iced-tea, lemonade
- 사진이 없는 메뉴는 자동으로 기존 이모지 아이콘으로 대체되어 보입니다.
- 권장 형식: jpg, 정사각형에 가까운 비율
